# Agent Study

面向 **高级后端 → Agent 后端 / AI 应用架构 / AI Tech Lead** 的学习与实践仓库。

## 目标

不是转成初级 Python / 算法工程师，也不是追逐 Agent 框架 API，而是把已有的软件工程、分布式系统、业务建模和企业系统经验迁移到 Agent 时代。

重点能力：

- Agent Core
- Agent Runtime
- Context Engineering
- Evaluation & Observability
- MCP / Tool / Skills
- RAG Engineering
- Workflow + Agent
- Security / Permission / Audit
- Production Agent

Python 已有基础，不单独安排学习阶段；在实际项目中按需补 FastAPI、Pydantic、asyncio 等工程能力。

## 文件

- [LEARNING_PLAN.md](./LEARNING_PLAN.md)：12 个月学习与工作规划
- [PROGRESS.md](./PROGRESS.md)：学习进度、产出与复盘跟踪

## 学习原则

1. **70% 项目实践 + 20% 深入阅读 + 10% 理论补充**。
2. 优先掌握机制，不追逐框架。
3. 每个阶段必须有代码、文档、评测或工作落地产出。
4. 学习与工作绑定，目标是让履历真正出现生产级 Agent 项目。
5. 重点积累 Runtime、Context、Evaluation、Enterprise Integration 四类能力。
